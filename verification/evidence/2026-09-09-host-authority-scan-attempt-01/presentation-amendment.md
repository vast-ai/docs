# Current-finding-only presentation

The user clarified during this scan that the reviewer and shareable HTML should
show the final finding, not superseded mistakes or the history of fixing them.

The current card must show the exact customer-facing statement, its current
disposition, the supporting source or observation and its limits, and the next
action for any real gap. Source excerpts should use named sections or code
locations that a reviewer can understand.

Remove prior-finding panels, transition-history controls, obsolete aggregate
test summaries and competing legacy V&V material from those review views.
Existing valid retained observations can still support a current finding; their
dates and limits must remain clear. This does not convert a dated observation
into a fresh runtime test.

Underlying frozen evidence remains internal input to the integrity checks. No
audit file is deleted, and no old outcome is silently relabelled as current.
This is a presentation change, not a change to the claim inventory or evidence
standard, and it does not authorize publication or human acceptance.

# Read the source before asking an owner

This scan covers the current 44 Host pages. The CLI and SDK wrappers are
reference-support layers, not additional Host workflows. This guide explains
source suitability; it is not itself evidence that a product claim is true.

| What the sentence says | First suitable authority | What that does not establish |
| --- | --- | --- |
| A CLI option, API field or configuration exists | Pinned canonical implementation, schema provenance and request mapping | Backend enforcement, a successful live operation or financial/legal terms |
| A provider has a stated obligation | The applicable published agreement or policy, matched to the exact clause | Account-specific acceptance, actual compliance or platform enforcement |
| A system or operator did something | Retained execution or UI observation with target, time, input, output and limitations | All machines, later versions or a whole workflow from one step |
| A recommendation, worked example or navigation instruction | Technical source/rationale, an independent calculation, or a destination check appropriate to its actual meaning | A platform policy merely because its heading mentions prices or contracts |

The public [Hosting Agreement](https://cloud.vast.ai/host/agreement) already has
specific sections for **Performance of Services**, **License and
Responsibilities**, **Operation and Maintenance**, **Intellectual Property and
Data Security**, and **Independent Contractors**. Its payment terms appear under
the inline **Hardware as a Service Payments** heading in the retained Use of
Hardware range. The published page has irregular HTML headings and no observed
section IDs: the review must show the named section and exact captured excerpt,
not invent a working anchor or imply that the whole agreement proves every claim.

The agreement's Provider–Vast term and an individual renter's contract term are
different subjects. The pinned CLI's price-increase help describes an accepted
new rate applying after the current rental term. That source can correct an
overbroad description of the CLI's published behaviour; it is not an independent
test of backend billing or legal enforcement.

The current [Compliance publication](https://vast.ai/compliance) and the
[October 2024 security article](https://vast.ai/article/security-and-compliance-at-vast-ai)
disagree about mandatory datacenter certification. Preserve both sources and
ask Product/Compliance which requirement applies. A source conflict is concrete;
the mere absence of a bound citation does not prove an owner is unavailable.

## Avoid circular proof

The Host sentence, another Host page repeating it, a generated review model,
an adjudication registry, a checksum, an audit summary and a Graphify connection
are not independent terminal product evidence. Trace the support to the actual
source or retained observation. A link check can legitimately use repository
files to show that a destination exists; it cannot validate the destination's
contract, financial or runtime claims.

The scan's provenance inventory distinguishes contextual/history links from
evidence-origin links. A bookkeeping cycle is not necessarily circular reasoning.
A claim supported only by itself or by its own summaries is not established.

## Decide what remains

- **UNVALIDATED:** suitable proof is not yet bound. Name the next source or
  observation to inspect; do not automatically demand a new owner decision.
- **FAIL:** a confirmed wording/source defect, an actually required missing
  citation, or an overstated proof claim. Preserve the original and link a retest.
- **BLOCKED:** a suitable check cannot proceed because a specific input,
  environment, permission, authorization or accountable decision is unavailable.
- **PASS:** the exact assertion is supported within the recorded scope. Partial
  source support stays partial, even when other parts of the sentence are easy
  to verify. Neither a PASS nor this report records human acceptance.

Owner escalation is appropriate after a real gap, conflict or applicability
question is identified. An existing applicable authoritative publication does
not require a second, invented approval simply because the subject is commercial
or legal.

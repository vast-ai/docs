## Host Responsibilities

While a rental contract is active:

- Keep the advertised machine online, stable, and performant. [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement) requires commercially best efforts for 24/7 availability, excluding scheduled preventative and remedial maintenance.
- Do not run local gaming, mining, benchmarks, display workloads, or background GPU jobs.
- Do not stop, inspect, modify, or interfere with renter containers because they appear idle.
- Keep renter data isolated. For the related privacy and safeguard duties, see [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement) and [Hosting Agreement — Intellectual Property and Data Security](https://cloud.vast.ai/host/agreement); these clauses do not substitute for configuring and checking isolation.
- Keep escalation contact details current in [Settings](https://cloud.vast.ai/settings/) so Vast can reach the right responder for urgent hosted-machine issues. [Hosting Agreement — License and Responsibilities](https://cloud.vast.ai/host/agreement) requires true, accurate, current account information and keeping it up to date.
- Follow the host agreement, applicable terms, export rules, and law. [Hosting Agreement — License and Responsibilities](https://cloud.vast.ai/host/agreement) requires compliance with applicable law and Vast policies.

An idle-looking rental can still be active. Renters may run notebooks, services, build jobs, CPU-heavy work, or bursty workloads.

## Can I Message A Client?

No. Hosts do not have an established direct client-message flow. If a workload looks broken, idle, abusive, or policy-sensitive, follow the escalation guidance below.

## Renter Reports And Host Logs

Renters can report machine issues from their instance using **Report Machine**. Report categories include startup failures, slow instance load, less disk space than requested, port issues, lower-than-expected performance, and other issues. The report can also include a written description from the renter.

When a report appears, treat it as a machine-health or contract-quality signal, not permission to inspect renter data. See [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement). Start with host-side evidence:

- Review user reports with [`vastai reports <machine_id>`](/cli/reference/reports).
- Pull daemon-side instance logs with [`vastai logs <instance_id> --daemon-logs`](/cli/reference/logs) when you have the affected instance ID.
- Check the host daemon log with `sudo tail -n 100 /var/lib/vastai_kaalia/kaalia.log`.
- Check kernel GPU, PCIe, AER, and Xid logs for hardware or driver symptoms.
- Compare the report with the machine's listing, port range, storage setup, recent maintenance, and any active contract terms.

Do not read renter files while investigating a report. See [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement).

Do not review private workload output while investigating a report. [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement), under Downloading, Storing, or Printing, prohibits reviewing Authorized User data.

Do not copy or share renter files or private workload output while investigating a report. [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement), under Downloading, Storing, or Printing, prohibits downloading, storing, reviewing, printing, or saving Authorized User data.

If the issue points to platform state, policy, abuse, account state, or a backend machine-record mismatch, collect timestamps, screenshots, report details, and host-side logs, then escalate to Vast support. For security cases, [Hosting Agreement — License and Responsibilities](https://cloud.vast.ai/host/agreement) requires cooperation with investigations and prompt notification of known or suspected account/software security breaches. For log commands and diagnostic collection, see [Host Diagnostics](/host/common-errors-diagnostics#logs).

## Restricted Activity

The published [Terms of Service](https://vast.ai/terms) list prohibited activities.

| Category | Published rule or response |
| --- | --- |
| Illegal or abusive activity | [Terms — Prohibited Activities items 3, 13, 14, and 21](https://vast.ai/terms) prohibit users from criminal or tortious activity, violations of law, and knowingly posting, transmitting, uploading, linking to, sending, or storing unlawful or abusive content. |
| Malware, spam, or interference | [Terms — Prohibited Activities items 5, 12, and 20](https://vast.ai/terms) prohibit users from interfering with or disrupting the Website or connected networks/services, uploading or transmitting harmful material including malware, and using the Services to send spam. [Hosting Agreement — License and Responsibilities](https://cloud.vast.ai/host/agreement) separately prohibits malicious code, interference with the software, and unauthorized access. |
| Platform abuse or security bypass | Escalate suspected attempts to bypass controls or disrupt systems. [Hosting Agreement — License and Responsibilities](https://cloud.vast.ai/host/agreement) prohibits interference and unauthorized access and requires prompt security notification. |
| Intellectual-property concerns | [Terms — Prohibited Activities item 15](https://vast.ai/terms) prohibit users from infringing or misappropriating third-party intellectual-property or other rights. Separately, [Hosting Agreement — Operation and Maintenance](https://cloud.vast.ai/host/agreement) prohibits reviewing Authorized User data. |
| Export-controlled or sanctioned use | [Terms — Export Compliance](https://vast.ai/terms) require users to comply with Export Control Laws and not export, re-export, transfer, or provide access to Services or derived technical data to a prohibited destination or person, or use the Services for a restricted end use, without first obtaining all required government authorizations. |
| Cryptocurrency mining | [Terms — Prohibited Activities item 22](https://vast.ai/terms) prohibit users who purchase credits for Website services with a credit card from cryptocurrency mining using Company or Provider resources; it does not state a blanket rule for every payment method. |

## Mining And Crypto-Adjacent Workloads

Some blockchain-adjacent workloads are AI inference or training; others may be mining, proof-of-work, or policy-sensitive token activity.

Hosts should not decide policy on behalf of Vast. If a renter asks whether a specific crypto workload is allowed, point them to the [Terms of Service](https://vast.ai/terms) or support.

## What To Do

| Situation | Action |
| --- | --- |
| Rental appears idle | Leave it running. |
| Renter reports a machine issue | Review user reports, collect host-side logs, and compare the report with listing, storage, ports, performance, and recent maintenance. |
| Rental affects machine stability | Check host hardware, thermals, power, drivers, Docker, daemon logs, and kernel GPU/PCIe logs. |
| Suspected abuse | Collect timestamps, symptoms, screenshots, and visible instance details; contact support. |
| Planned maintenance needed | Use [maintenance windows](/host/maintenance-windows) and offer-end-date planning. |
| Stop new rentals | Unlist the machine; existing contracts continue. |
| Expired contract or stale storage | Use documented cleanup flows in [Remove or Recreate](/host/removing-recreating-machines). |

Pin a machine field (location, bandwidth) to a manual value

<Note>This is a **host** command, used for managing machines you are renting out on Vast.ai.</Note>

## Usage

```bash
vastai set machine-override FIELD VALUE [--ids IDS] [--host-id HOST_ID] [--reason REASON]
```

## Arguments

<ParamField path="field" type="string" required>
  field to override: `geolocation`, `inet_up` or `inet_down`
</ParamField>

<ParamField path="value" type="string" required>
  the value: `"Region, CC"` for geolocation (e.g. `"Guangdong, CN"`), Mbps for inet_up/inet_down
</ParamField>

## Options

<ParamField path="--ids" type="string">
  comma-separated machine ids (default: all of the host's machines)
</ParamField>

<ParamField path="--host-id" type="integer">
  host whose machines to set (admins only)
</ParamField>

<ParamField path="--reason" type="string">
  why the value is overridden (required for an admin override)
</ParamField>

## Description

Sets a manual value for a machine field. Automatic updates (the IP location lookup, speed tests) keep it until it is cleared with [`vastai clear machine-override`](/cli/reference/clear-machine-override).

| Field | Who can set it | Value |
| --- | --- | --- |
| `geolocation` | the machine's host, or an admin | `"Region, CC"` in the US, China, Canada and Russia (e.g. `"Guangdong, CN"`), otherwise `"Country, CC"` (e.g. `"Germany, DE"`) |
| `inet_up` | admins only | upload bandwidth in Mbps |
| `inet_down` | admins only | download bandwidth in Mbps |

A value set by an admin is locked: the host cannot change or clear it. See [Fix your machine's listed location](/host/machine-location).

## Examples

```bash
vastai set machine-override geolocation "Guangdong, CN" --ids 12345,12346
vastai set machine-override geolocation "Germany, DE"
```

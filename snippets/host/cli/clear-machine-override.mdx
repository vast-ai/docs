Remove a manual machine field value so automatic detection takes over

<Note>This is a **host** command, used for managing machines you are renting out on Vast.ai.</Note>

## Usage

```bash
vastai clear machine-override FIELD [--ids IDS] [--host-id HOST_ID] [--reason REASON]
```

## Arguments

<ParamField path="field" type="string" required>
  field whose override to remove: `geolocation`, `inet_up` or `inet_down`
</ParamField>

## Options

<ParamField path="--ids" type="string">
  comma-separated machine ids (default: all of the host's machines)
</ParamField>

<ParamField path="--host-id" type="integer">
  host whose machines to clear (admins only)
</ParamField>

<ParamField path="--reason" type="string">
  why the override is cleared (required for an admin)
</ParamField>

## Description

Removes a value set with [`vastai set machine-override`](/cli/reference/set-machine-override). For `geolocation` the detected location is restored right away; bandwidth returns to the latest speed test. A value set by Vast support can only be cleared by support.

## Examples

```bash
vastai clear machine-override geolocation --ids 12345
```

Perform a self-test on the specified machine

<Note>This is a **host** command, used for managing machines you are renting out on Vast.ai.</Note>

## Usage

```bash
vastai self-test machine <machine_id> [--debugging] [--explain] [--api-key API_KEY] [--url URL] [--retry RETRY] [--raw] [--ignore-requirements]
```

## Arguments

<ParamField path="machine_id" type="string" required>
  Machine ID
</ParamField>

## Options

<ParamField path="--debugging" type="boolean">
  Enable debugging output
</ParamField>

<ParamField path="--ignore-requirements" type="boolean">
  Skip later preflight checks, including offer reliability at or below 0.90. Does not bypass `currently_rented`, `zero_active_offers`, or `offline_or_not_listed`.
</ParamField>

## Description

This command rents a test instance on a live offer, runs the tests, then destroys that instance. The machine must be listed. It refuses with `currently_rented`, `zero_active_offers`, or `offline_or_not_listed`. A scoped API key needs `machine_read`, `instance_read`, `instance_write`, and `misc` on that one key.

## Examples

```bash
vastai self-test machine 12345
vastai self-test machine 12345 --debugging
vastai self-test machine 12345 --explain
vastai self-test machine 12345 --api-key YOUR_API_KEY
```

## Global Options

The following options are available for all commands:

| Option | Description |
| --- | --- |
| `--url URL` | Server REST API URL |
| `--retry N` | Total attempts (default 3; use 1 for a single request; 0 sends nothing) |
| `--raw` | Output machine-readable JSON |
| `--explain` | Verbose explanation of API calls |
| `--api-key KEY` | API key (defaults to `~/.config/vastai/vast_api_key`) |

**Simple**

Replace `CURRENT_SETUP_KEY` with the key from the current [Host Setup command](https://cloud.vast.ai/host/setup/), and replace the storage device and ports with your host values. Use `--no-driver` only after `nvidia-smi` shows all GPUs.

```bash
mkdir -p ~/vast-install && cd ~/vast-install &&
wget https://console.vast.ai/install -O install &&
sudo python3 ./install "CURRENT_SETUP_KEY" --no-driver \
  --docker-partition /dev/mapper/vg1-lv--1 --ports 40000 40799
```

<Accordion title="Advanced">

To enter the setup key at a prompt instead of including it in shell history, run this Bash version. Choose this version or the Simple version; run the installer once.

```bash
mkdir -p ~/vast-install && cd ~/vast-install &&
wget https://console.vast.ai/install -O install &&
IFS= read -r -s -p "Paste current Vast host setup key: " VAST_HOST_KEY &&
printf '\n' &&
[ -n "$VAST_HOST_KEY" ] &&
sudo python3 ./install "$VAST_HOST_KEY" --no-driver \
  --docker-partition /dev/mapper/vg1-lv--1 --ports 40000 40799
```

| Option | Use |
| --- | --- |
| `--no-driver` | Keep the NVIDIA driver you already installed and checked. |
| `--docker-partition` | Use the prepared Docker storage device. See [Storage Setup](/host/storage-setup). |
| `--ports` | Set the first and last direct ports. Match your TCP and UDP forwarding rules. |

</Accordion>

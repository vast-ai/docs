Remove a manual machine field value so automatic detection takes over again.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

## Signature

```python
VastAI.clear_machine_override(field: str, machine_ids: Optional[List[int]] = None, host_id: Optional[int] = None, reason: Optional[str] = None) -> dict
```

## Parameters

<ParamField path="field" type="str" required>
  `"geolocation"`, `"inet_up"` or `"inet_down"`
</ParamField>

<ParamField path="machine_ids" type="Optional[List[int]]">
  machines to clear; omitted means all of the host's machines
</ParamField>

<ParamField path="host_id" type="Optional[int]">
  host whose machines to clear (admins only; defaults to the caller)
</ParamField>

<ParamField path="reason" type="Optional[str]">
  why the override is cleared; required when an admin clears it
</ParamField>

## Returns

`dict`: `machine_ids` cleared, `restored` (the detected value restored per machine, for geolocation) and `msg`.

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.clear_machine_override("geolocation", machine_ids=[12345])
print(result["msg"])
```

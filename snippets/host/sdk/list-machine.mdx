Lists a machine for rent with optional pricing and configuration parameters.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

<Note>
SLA listing parameters are not in the published Python SDK yet — use the console (**Set Pricing → SLA**) or REST `PUT /api/v0/machines/create_asks/` ([SLA Offers](/host/sla-offers#api-for-automation)). On an already-listed SLA machine, `list_machine()` does not send SLA fields, so Claim and Confidence stay. After an unlist, a relist creates a new ask **without** SLA. `list_machine()` cannot send `hidden_listing`, so a reprice makes a hidden listing public. It also sends `vol_size` and `duration` as `null` unless you pass them: null `vol_size` can create a volume offer at half the free disk, and null `duration` clears auto-renew. Pass `vol_size=0` to skip a new volume offer. To keep auto-renew, pass `duration` again (seconds or a string such as `"30 days"`) on every call. Never pass `duration` together with `end_date`. `end_date` accepts a date string or a Unix timestamp. Pass `min_chunk` as well (null `min_chunk` is HTTP 400). Update hidden SLA listings with REST and send `hidden_listing` explicitly.
</Note>

## Signature

```python
VastAI.list_machine(
    id: int,
    price_gpu: Optional[float] = None,
    price_disk: Optional[float] = None,
    price_inetu: Optional[float] = None,
    price_inetd: Optional[float] = None,
    discount_rate: Optional[float] = None,
    min_chunk: Optional[int] = None,
        end_date: Optional[Union[str, int, float]] = None,
        duration: Optional[str] = None,
        vol_size: Optional[int] = None,
        vol_price: Optional[float] = None,
) -> str
```

## Parameters

<ParamField path="id" type="int" required>
  Machine ID to list.
</ParamField>

<ParamField path="price_gpu" type="Optional[float]">
  GPU rental price in $/hour for active instances.
</ParamField>

<ParamField path="price_disk" type="Optional[float]">
  Storage price in $/GB/month for inactive instances.
</ParamField>

<ParamField path="price_inetu" type="Optional[float]">
  Upload bandwidth price in $/GB.
</ParamField>

<ParamField path="price_inetd" type="Optional[float]">
  Download bandwidth price in $/GB.
</ParamField>

<ParamField path="discount_rate" type="Optional[float]">
  Max long-term prepay discount rate fraction (default 0.4).
</ParamField>

<ParamField path="min_chunk" type="Optional[int]">
  Minimum GPUs that must be rented together (GPU slicing).
</ParamField>

<ParamField path="end_date" type="Optional[str]">
  Offer expiration (Unix timestamp or MM/DD/YYYY).
</ParamField>

## Returns

`str`. The return value is the API response body as text (JSON).

## Example

```python
from vastai import VastAI
import os

client = VastAI(api_key="YOUR_API_KEY")
# Replace price_disk and min_chunk with this machine's current values.
# CURRENT_END_DATE_UNIX must be that machine's future end_date. A past value expires the offer.
# vol_size=0 avoids creating a volume offer.
CURRENT_END_DATE_UNIX = int(os.environ["CURRENT_END_DATE_UNIX"])
result = client.list_machine(id=12345, price_gpu=3.50, price_disk=0.15, min_chunk=1, vol_size=0, end_date=CURRENT_END_DATE_UNIX)
print(result)
```

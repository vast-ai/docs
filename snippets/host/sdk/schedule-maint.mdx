Schedule maintenance for a machine.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

## Signature

```python
VastAI.schedule_maint(id: int, sdate, duration, category: str = "not provided") -> dict
```

## Parameters

<ParamField path="id" type="int" required>
  id
</ParamField>

<ParamField path="sdate" type="Optional[float]">
  sdate
</ParamField>

<ParamField path="duration" type="Optional[float]">
  Duration of the maintenance window, in hours.
</ParamField>

<ParamField path="category" type="str" default="not provided">
  Reason for the maintenance window.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.schedule_maint(id=12345)
print(result)
```

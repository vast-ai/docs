Pin a machine field (geolocation, inet_up, inet_down) to a manual value until cleared.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

## Signature

```python
VastAI.set_machine_override(field: str, value, machine_ids: Optional[List[int]] = None, host_id: Optional[int] = None, reason: Optional[str] = None) -> dict
```

## Parameters

<ParamField path="field" type="str" required>
  `"geolocation"` (the machine's host or an admin), or `"inet_up"` / `"inet_down"` in Mbps (admins only)
</ParamField>

<ParamField path="value" type="str | float" required>
  `"Region, CC"` or `"Country, CC"` for geolocation (e.g. `"Guangdong, CN"`); a number of Mbps for bandwidth
</ParamField>

<ParamField path="machine_ids" type="Optional[List[int]]">
  machines to set; omitted means all of the host's machines
</ParamField>

<ParamField path="host_id" type="Optional[int]">
  host whose machines to set (admins only; defaults to the caller)
</ParamField>

<ParamField path="reason" type="Optional[str]">
  why the value is overridden; required when an admin sets it
</ParamField>

## Returns

`dict`: `machine_ids` set, `locked_machine_ids` (values set by Vast support, which a host cannot change), `skipped_machine_ids` (IDs that are not the host's) and `msg`.

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.set_machine_override("geolocation", "Guangdong, CN", machine_ids=[12345])
print(result["msg"])
```

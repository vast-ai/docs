Show maintenance information for host machines.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

## Signature

```python
VastAI.show_maints(ids: str) -> list[dict]
```

## Parameters

<ParamField path="ids" type="str" required>
  Machine IDs to show maintenance windows for.
</ParamField>

## Returns

`list[dict]`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.show_maints(ids="...")
print(result)
```

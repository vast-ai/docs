Defragment machines.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

## Signature

```python
VastAI.defrag_machines(ids: List[int]) -> dict
```

## Parameters

<ParamField path="ids" type="List[int]" required>
  Machine IDs to defragment.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.defrag_machines(ids=[12345])
print(result)
```

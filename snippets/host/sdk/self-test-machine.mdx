Perform a self-test on the specified machine.

<Note>This is a **host** method, used for managing machines you are renting out on Vast.ai.</Note>

<Warning>This method is **not implemented** in the SDK and will raise `NotImplementedError` when called. Use the CLI `vastai self_test_machine` instead.</Warning>

## Signature

```python
VastAI.self_test_machine(
    machine_id,
    **kwargs
)
```

## Parameters

<ParamField path="machine_id" type="int" required>
  ID of the machine to self-test.
</ParamField>

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
# Not implemented in SDK — raises NotImplementedError
# Use CLI: vastai self_test_machine MACHINE_ID
```

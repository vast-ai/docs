Apply changes during planned maintenance after reviewing active rentals. Replace this example range with the ports forwarded by your router and firewall.

**Simple**

```bash
printf %s "40000-40799" | sudo tee /var/lib/vastai_kaalia/host_port_range &&
sudo systemctl restart vastai.service
```

<Accordion title="Advanced">

Read back the saved range and check daemon output after the restart:

```bash
sudo cat /var/lib/vastai_kaalia/host_port_range
sudo tail -n 50 /var/lib/vastai_kaalia/kaalia.log
```

`printf %s` writes the dash-separated range without a trailing newline. The `&&` restarts the service only if the write succeeds. Reading the file confirms the configured value; use an external connection to verify forwarding.

</Accordion>

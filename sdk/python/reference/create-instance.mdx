Create a new instance from an offer/ask ID returned by search.

<Note>
**SLA:** `target_reliability` is not available on `create_instance()` today. Use the web console or REST `PUT /api/v0/asks/{id}/` to enable the SLA — see [SLA](/guides/instances/choosing/sla-coverage#api-automation). Use the same storage number in search (`allocated_storage` or `--storage`) and in the rent body (`disk`).
</Note>

```python
VastAI.create_instance(
    id: int,
    image: Optional[str] = None,

    env: Optional[Union[str, dict]] = None,
    price: Optional[float] = None,
    label: Optional[str] = None,
    extra: Optional[str] = None,
    onstart_cmd: Optional[str] = None,
    login: Optional[str] = None,
    python_utf8: bool = False,
    lang_utf8: bool = False,
    jupyter_lab: bool = False,
    jupyter_dir: Optional[str] = None,
    force: bool = False,
    cancel_unavail: bool = False,
    template_hash: Optional[str] = None,
    user: Optional[str] = None,
    runtype: Optional[str] = None,
    args: Optional[list] = None,
    volume_info: Optional[dict] = None,

```

## Parameters

<ParamField path="id" type="int" required>
  Offer/ask ID from search offers (same value as CLI create-instance). This is not a running instance ID.
</ParamField>

<ParamField path="image" type="Optional[str]">
  Docker container image to launch. Pass `image`, `template_hash`, or both. A template can supply the image.
</ParamField>

<ParamField path="disk" type="float" default="10">
  size of local disk partition in GB
</ParamField>

<ParamField path="env" type="Optional[Union[str, dict]]">
  env variables and port mapping options, surround with ''
</ParamField>

<ParamField path="price" type="Optional[float]">
  On-demand price in $/hour when you set a price on the rental. An SLA rental is on-demand. Do not set `price` together with `bid_price`.
</ParamField>

<ParamField path="label" type="Optional[str]">
  label to set on the instance
</ParamField>

<ParamField path="extra" type="Optional[str]">
  Extra Docker create options, passed through as a string.
</ParamField>

<ParamField path="onstart_cmd" type="Optional[str]">
  contents of onstart script as single argument
</ParamField>

<ParamField path="login" type="Optional[str]">
  docker login arguments for private repo authentication, surround with ''
</ParamField>

<ParamField path="python_utf8" type="bool">
  Workaround for images with locale problems: set python's locale to C.UTF-8
</ParamField>

<ParamField path="lang_utf8" type="bool">
  Workaround for images with locale problems: install and generate locales before instance launch, and set locale to C.UTF-8
</ParamField>

<ParamField path="jupyter_lab" type="bool">
  For runtype 'jupyter', Launch instance with jupyter lab
</ParamField>

<ParamField path="jupyter_dir" type="Optional[str]">
  For runtype 'jupyter', directory in instance to use to launch jupyter. Defaults to image's working directory
</ParamField>

<ParamField path="force" type="bool">
  Skip sanity checks when creating from an existing instance
</ParamField>

<ParamField path="cancel_unavail" type="bool">
  Return error if scheduling fails (rather than creating a stopped instance)
</ParamField>

<ParamField path="template_hash" type="Optional[str]">
  Create instance from template info
</ParamField>

<ParamField path="user" type="Optional[str]">
  User to use with docker create. This breaks some images, so only use this if you are certain you need it.
</ParamField>

<ParamField path="runtype" type="Optional[str]">
  Launch mode. Other fields on this page use values such as `ssh` and `jupyter`.
</ParamField>

<ParamField path="args" type="Optional[list]">
  list of arguments passed to container ENTRYPOINT. Onstart is recommended for this purpose. (must be last argument)
</ParamField>

<ParamField path="volume_info" type="Optional[dict]">
  Optional volume to attach when the instance is created. See the CLI flags `--create-volume` and `--link-volume`.
</ParamField>

<ParamField path="bid_price" type="Optional[float]">
  (OPTIONAL) create an INTERRUPTIBLE instance with per machine bid price in $/hour. An SLA does not apply to interruptible rentals.
</ParamField>

<ParamField path="ssh" type="bool">
  Launch as an ssh instance type
</ParamField>

<ParamField path="jupyter" type="bool">
  Launch as a jupyter instance instead of an ssh instance
</ParamField>

<ParamField path="direct" type="bool">
  Use (faster) direct connections for jupyter & ssh
</ParamField>

<ParamField path="create_volume" type="Optional[int]">
  Create a new local volume using an ID returned from the "search volumes" command and link it to the new instance
</ParamField>

<ParamField path="link_volume" type="Optional[int]">
  ID of an existing rented volume to link to the instance during creation. (returned from "show volumes" cmd)
</ParamField>

<ParamField path="volume_size" type="Optional[float]">
  Size of the volume to create in GB. Only usable with --create-volume (default 15GB)
</ParamField>

<ParamField path="mount_path" type="Optional[str]">
  The path to the volume from within the new instance container. e.g. /root/volume
</ParamField>

<ParamField path="volume_label" type="Optional[str]">
  (optional) A name to give the new volume. Only usable with --create-volume
</ParamField>

## Returns

`dict`. On success, the response includes `new_contract` — the rental contract / instance ID to use with destroy and `GET /api/v1/instances/` (`vastai show instances-v1`). The `id` you pass to `create_instance()` is the offer/ask ID from search, not `new_contract`. `create_instance()` cannot set `target_reliability`; use REST for an SLA.

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.create_instance(
    id=12345,  # offer/ask ID from search, not a running instance ID
    image="pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime",
    disk=50,
)
print(result)
```

**SLA via REST:** `create_instance()` cannot set `target_reliability`. If you only use Python, rent with REST and pass the same target you searched with:

```python
import requests

offer_id = 12345  # path id: offer/ask ID from search, not a running instance ID
response = requests.put(
    f"https://console.vast.ai/api/v0/asks/{offer_id}/",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "image": "pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime",
        "disk": 50,
        "target_reliability": 0.95,
    },
    timeout=60,
)
response.raise_for_status()
print(response.json())  # new_contract is the rental instance ID
```

The same call with curl:

```bash
curl -s -X PUT "https://console.vast.ai/api/v0/asks/OFFER_ID/" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "image": "pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime",
    "disk": 50,
    "target_reliability": 0.95
  }'
```

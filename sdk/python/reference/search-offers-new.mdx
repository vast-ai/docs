Search for GPU offers using the new /search/asks/ endpoint.

## Signature

```python
VastAI.search_offers_new(
    query=None,
    type: str = "on-demand",
    order: str = "score-",
    limit: Optional[int] = None,
    storage: float = 5.0,
    no_default: bool = False
) -> list
```

## Parameters

<ParamField path="query" type="str" default="None">
  Search query string or filter criteria.
</ParamField>

<ParamField path="type" type="str" default="on-demand">
  Type of offer: "on-demand" or "interruptible".
</ParamField>

<ParamField path="order" type="str" default="score-">
  Sort order for results.
</ParamField>

<ParamField path="limit" type="int" default="None">
  Maximum number of results to return.
</ParamField>

<ParamField path="storage" type="float" default="5.0">
  Minimum storage size in GB.
</ParamField>

<ParamField path="no_default" type="bool" default="False">
  If True, do not apply default query filters.
</ParamField>

## Returns

`list`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.search_offers_new(type="on-demand", limit=10)
print(result)
```

Search for network volume offers.

## Signature

```python
VastAI.search_network_volumes(
    query: Optional[Union[str, dict]] = None,
    order: Optional[Union[str, list]] = None,
    limit: Optional[int] = None,
    storage: float = 1.0,
    no_default: bool = False
) -> list[dict]
```

## Parameters

<ParamField path="query" type="Union[str, dict]" default="None">
  Search query string or dict of filter criteria.
</ParamField>

<ParamField path="order" type="Union[str, list]" default="None">
  Sort order for results.
</ParamField>

<ParamField path="limit" type="int" default="None">
  Maximum number of results to return.
</ParamField>

<ParamField path="storage" type="float" default="1.0">
  Minimum storage size in GB.
</ParamField>

<ParamField path="no_default" type="bool" default="False">
  If True, do not apply default query filters.
</ParamField>

## Returns

`list[dict]`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.search_network_volumes(storage=10.0, limit=5)
print(result)
```

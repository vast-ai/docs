Remove a 2FA method from your account.

## Signature

```python
VastAI.tfa_delete(
    **kwargs
) -> dict
```

## Parameters

<ParamField path="**kwargs" type="dict">
  Keyword arguments identifying the 2FA method to remove.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.tfa_delete(method_id="totp")
print(result)
```

Create a new network volume.

## Signature

```python
VastAI.create_network_volume(
    id: int,
    size: float = 15,
    name: Optional[str] = None
) -> dict
```

## Parameters

<ParamField path="id" type="int" required>
  The datacenter or region ID where the volume will be created.
</ParamField>

<ParamField path="size" type="float" default="15">
  Size of the network volume in GB.
</ParamField>

<ParamField path="name" type="str" default="None">
  Optional name for the network volume.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.create_network_volume(id=1, size=50, name="my-volume")
print(result)
```

Return benchmarks using the paginated API; for manual pagination.

## Signature

```python
VastAI.search_benchmarks_v1(
    params: dict
) -> dict
```

## Parameters

<ParamField path="params" type="dict" required>
  Query parameters for the benchmark search, including pagination options.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.search_benchmarks_v1(params={"page": 1, "limit": 50})
print(result)
```

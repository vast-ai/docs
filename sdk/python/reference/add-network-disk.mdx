Add a network disk to a physical cluster.

## Signature

```python
VastAI.add_network_disk(
    machines: List[int],
    mount_point: str,
    disk_id: Optional[int] = None
) -> dict
```

## Parameters

<ParamField path="machines" type="List[int]" required>
  List of machine IDs to attach the disk to.
</ParamField>

<ParamField path="mount_point" type="str" required>
  Mount point path for the network disk.
</ParamField>

<ParamField path="disk_id" type="int" default="None">
  Existing disk ID to attach. If None, a new disk is created.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.add_network_disk(
    machines=[101, 102],
    mount_point="/mnt/shared"
)
print(result)
```

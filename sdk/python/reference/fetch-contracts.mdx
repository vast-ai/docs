Fetch contracts, optionally filtered by label.

## Signature

```python
VastAI.fetch_contracts(
    label: Optional[str] = None,
    contract_ids: Optional[list] = None
) -> list
```

## Parameters

<ParamField path="label" type="str" default="None">
  Filter contracts by label.
</ParamField>

<ParamField path="contract_ids" type="list" default="None">
  List of specific contract IDs to fetch.
</ParamField>

## Returns

`list`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.fetch_contracts()
print(result)

# Filter by label
result = client.fetch_contracts(label="my-project")
print(result)
```

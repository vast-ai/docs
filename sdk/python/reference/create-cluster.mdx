Create a Vast cluster.

## Signature

```python
VastAI.create_cluster(
    subnet: str,
    manager_id: int
) -> dict
```

## Parameters

<ParamField path="subnet" type="str" required>
  Subnet CIDR for the cluster network.
</ParamField>

<ParamField path="manager_id" type="int" required>
  Machine ID to designate as the cluster manager.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.create_cluster(subnet="10.0.0.0/24", manager_id=101)
print(result)
```

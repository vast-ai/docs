Update a 2FA method's settings.

## Signature

```python
VastAI.tfa_update(
    **kwargs
) -> dict
```

## Parameters

<ParamField path="**kwargs" type="dict">
  Keyword arguments for the 2FA method settings to update.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.tfa_update(method_id="totp", enabled=True)
print(result)
```

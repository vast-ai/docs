List the backups Vast has taken of your instances and volumes.

## Signature

```python
VastAI.show_instance_backups(
    contract_id: Optional[int] = None
) -> list[dict]
```

## Parameters

<ParamField path="contract_id" type="int" default="None">
  Filter backups to a specific contract ID.
</ParamField>

## Returns

`list[dict]`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.show_instance_backups()
print(result)

# Filter by contract
result = client.show_instance_backups(contract_id=12345)
print(result)
```

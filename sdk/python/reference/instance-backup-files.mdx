Objects stored for one backup, plus a short-lived token to fetch them.

## Signature

```python
VastAI.instance_backup_files(
    contract_id: int
) -> dict
```

## Parameters

<ParamField path="contract_id" type="int" required>
  The contract ID of the backup to retrieve files for.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.instance_backup_files(contract_id=12345)
print(result)
```

Complete 2FA login by verifying code.

## Signature

```python
VastAI.tfa_login(
    **kwargs
) -> dict
```

## Parameters

<ParamField path="**kwargs" type="dict">
  Keyword arguments including the 2FA verification code.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.tfa_login(code="123456")
print(result)
```

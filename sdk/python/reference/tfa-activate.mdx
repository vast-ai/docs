Activate a new 2FA method by verifying the code.

## Signature

```python
VastAI.tfa_activate(
    **kwargs
) -> dict
```

## Parameters

<ParamField path="**kwargs" type="dict">
  Keyword arguments including the verification code and method details.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.tfa_activate(code="123456")
print(result)
```

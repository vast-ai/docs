Update an existing scheduled job.

## Signature

```python
VastAI.update_scheduled_job(
    id: int,
    request_body,
    **kwargs
) -> dict
```

## Parameters

<ParamField path="id" type="int" required>
  The ID of the scheduled job to update.
</ParamField>

<ParamField path="request_body" type="str" required>
  The updated request body for the job.
</ParamField>

<ParamField path="**kwargs" type="dict">
  Additional keyword arguments for job configuration.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.update_scheduled_job(
    id=12345,
    request_body='{"key": "value"}'
)
print(result)
```

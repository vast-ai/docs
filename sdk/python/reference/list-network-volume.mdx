List disk space for rent as a network volume.

## Signature

```python
VastAI.list_network_volume(
    disk_id: int,
    **kwargs
) -> dict
```

## Parameters

<ParamField path="disk_id" type="int" required>
  The disk ID to list as a network volume.
</ParamField>

<ParamField path="**kwargs" type="dict">
  Additional keyword arguments for listing configuration.
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.list_network_volume(disk_id=12345)
print(result)
```

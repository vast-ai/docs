Create a new API key.

## Signature

```python
VastAI.create_api_key(
    name: Any,
    permissions: Any,
    key_params: Any = None,
    lifetime_sec: Any = None
) -> dict
```

## Parameters

<ParamField path="name" type="Any" required>
  name of the api-key
</ParamField>

<ParamField path="permissions" type="Any" required>
  
</ParamField>

<ParamField path="key_params" type="Any">
  dict (or JSON object string) binding the `$name` parameters the permissions mention, e.g. `{"$instance_id": 1234}`. A key created with a pinned key keeps its pins.
</ParamField>

<ParamField path="lifetime_sec" type="Any">
  seconds the key lives (60 or more); it ends no later than the key it is created with. Default: no expiry of its own
</ParamField>

## Returns

`dict`

## Example

```python
from vastai import VastAI

client = VastAI(api_key="YOUR_API_KEY")
result = client.create_api_key(name="value", permissions="value")
print(result)
```

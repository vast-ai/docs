Reject one or more pending host price increases

## Usage

```bash
vastai reject price-increase ID [ID ...] [--yes]
```

## Arguments

<ParamField path="ids" type="integer" required>
  One or more instance IDs to reject price increases for
</ParamField>

## Options

<ParamField path="--yes" type="boolean">
  Skip the interactive confirmation prompt. Required when stdin is not a TTY (alias: `-y`)
</ParamField>

## Description

Tombstones the matching pending rows on the backend (no cutover follows). Use `vastai show pending-price-increases` to review the rows first. The CLI sends one PUT per instance ID.

**Exit codes:**
- `0` — every requested row was rejected
- `1` — at least one row failed (non-stale)
- `2` — at least one row was stale

## Examples

```bash
# Reject price increase for a single instance
vastai reject price-increase 456 --yes

# Reject for multiple instances
vastai reject price-increase 1 2 3 --yes
```

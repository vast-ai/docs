Create a new network volume from an offer ID

## Usage

```bash
vastai create network-volume ID [OPTIONS]
```

## Arguments

<ParamField path="id" type="integer" required>
  ID of the network volume offer (returned from `search network-volumes`)
</ParamField>

## Options

<ParamField path="-s" type="float" default="15">
  Size in GB of the network volume (alias: `--size`)
</ParamField>

<ParamField path="-n" type="string">
  Optional name for the network volume (alias: `--name`)
</ParamField>

## Description

Creates a network volume from an offer ID returned by `search network-volumes`. Each offer ID can be used to create multiple volumes, provided the total size does not exceed the offer's available space.

## Examples

```bash
# Create a 50GB network volume from offer 12345
vastai create network-volume 12345 --size 50

# Create a named network volume
vastai create network-volume 12345 --size 100 --name "training-data"
```

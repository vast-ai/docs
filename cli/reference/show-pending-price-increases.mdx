List pending host price-increase challenges for the authenticated user

## Usage

```bash
vastai show pending-price-increases [OPTIONS]
```

## Options

<ParamField path="-q" type="boolean">
  Print only `pending_price_increase_id` values, one per line (alias: `--quiet`)
</ParamField>

## Description

Lists every pending price-increase challenge the backend has open for you. Each row shows the per-resource old → new prices and the cutover boundary: the new rate applies only after each contract's current end date — your remaining time on the current term is billed at the original price.

Pipe the pending IDs to `vastai accept price-increase` or `vastai reject price-increase`.

## Examples

```bash
# List all pending price increases
vastai show pending-price-increases

# Get just the IDs (one per line, for scripting)
vastai show pending-price-increases --quiet

# Get raw JSON output
vastai show pending-price-increases --raw
```

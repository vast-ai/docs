Remove a 2FA method from your account

## Usage

```bash
vastai tfa delete [--id-to-delete ID] [--code CODE] [--method-type METHOD_TYPE] [--secret SECRET] [--backup-code BACKUP_CODE] [--method-id ID]
```

## Options

<ParamField path="-id" type="string">
  ID of the 2FA method to delete (see `tfa status`) (alias: `--id-to-delete`)
</ParamField>

<ParamField path="-c" type="string">
  2FA code to authorize deletion (alias: `--code`)
</ParamField>

<ParamField path="-t" type="string">
  2FA Method type (alias: `--method-type`). Allowed values: `email`, `sms`, `totp`
</ParamField>

<ParamField path="-s" type="string">
  Secret token, required for SMS or Email 2FA (alias: `--secret`)
</ParamField>

<ParamField path="-bc" type="string">
  One-time backup code (alias: `--backup-code`)
</ParamField>

<ParamField path="--method-id" type="string">
  2FA Method ID to use for authentication
</ParamField>

## Description

Remove a 2FA method. Requires 2FA verification. If `--id-to-delete` is not specified, the method used to authenticate will be deleted. Use `vastai tfa status` to see method IDs.

## Examples

```bash
vastai tfa delete --id-to-delete 123 --method-type email --secret abc123def456 -c 456789
```

```bash
vastai tfa delete --id-to-delete 123 --method-type totp --code 456789
```

```bash
vastai tfa delete -id 123 --method-type sms --secret abc123def456 -c 456789
```

```bash
vastai tfa delete --id-to-delete 123 --backup-code ABCD-EFGH-IJKL
```

```bash
vastai tfa delete -id 123 --method-id 456 -c 456789
```

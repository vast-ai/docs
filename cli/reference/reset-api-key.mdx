Reset your API key and receive a new one

## Usage

```bash
vastai reset api-key
```

## Description

Resets your current API key and generates a new one. The new key is printed to stdout. After resetting, update your local key file or environment variable with the new key. You can also retrieve your new key from the website.

## Examples

```bash
# Reset your API key
vastai reset api-key
```

## Global Options

The following options are available for all commands:

| Option | Description |
| --- | --- |
| `--url URL` | Server REST API URL |
| `--retry N` | Retry limit |
| `--raw` | Output machine-readable JSON |
| `--explain` | Verbose explanation of API calls |
| `--api-key KEY` | API key (defaults to `~/.config/vastai/vast_api_key`) |

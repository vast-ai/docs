List workers on an endpoint group with status and measured performance

## Usage

```bash
vastai get endpt-workers ID
```

## Arguments

<ParamField path="id" type="integer" required>
  ID of the endpoint group whose workers to list
</ParamField>

## Description

Lists all workers attached to a specific serverless endpoint group, showing each worker's ID, status, GPU name, and measured performance (e.g. tokens/s for LLMs).

## Examples

```bash
# List workers for endpoint group 21979
vastai get endpt-workers 21979

# Get raw JSON output
vastai get endpt-workers 21979 --raw
```

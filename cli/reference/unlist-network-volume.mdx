[Host] Unlist a network volume offer

## Usage

```bash
vastai unlist network-volume OFFER_ID
```

## Arguments

<ParamField path="id" type="integer" required>
  ID of the network volume offer to unlist
</ParamField>

## Description

Removes a network volume offer from the marketplace. This is a host-side command for machine operators.

## Examples

```bash
# Unlist network volume offer 42
vastai unlist network-volume 42
```

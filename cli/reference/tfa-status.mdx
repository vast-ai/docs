Show your current 2FA status.

## Usage

```bash
vastai tfa status
```

## Description

Display the current two-factor authentication status for your account, including:

- Whether 2FA is enabled
- List of active 2FA methods
- Number of backup codes remaining

## Examples

```bash
vastai tfa status
```

[Host] Show network disks associated with your account

## Usage

```bash
vastai show network-disks
```

## Description

Displays all network disks associated with your host account, grouped by cluster. For each cluster, shows the network disk details and the machines connected to it with their mount points. This is a host-side command for machine operators.

## Examples

```bash
# Show all network disks
vastai show network-disks

# Get raw JSON output
vastai show network-disks --raw
```

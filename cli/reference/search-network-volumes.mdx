Search for network volume offers using a custom query

## Usage

```bash
vastai search network-volumes [OPTIONS] [query]
```

## Arguments

<ParamField path="query" type="string">
  Query to search for. Default: `external=false verified=true disk_space>=1`. Pass `-n` to ignore the default
</ParamField>

## Options

<ParamField path="-n" type="boolean">
  Disable default query (alias: `--no-default`)
</ParamField>

<ParamField path="--limit" type="integer">
  Maximum number of results to return
</ParamField>

<ParamField path="--storage" type="float" default="1.0">
  Amount of storage to use for pricing, in GiB (default: 1.0)
</ParamField>

<ParamField path="-o" type="string" default="score-">
  Comma-separated list of fields to sort on. Postfix with `-` for descending (alias: `--order`)
</ParamField>

## Description

Query syntax:

```
query     = comparison comparison...
comparison = field op value
field      = <name of a field>
op         = one of: <, <=, ==, !=, >=, >, in, notin
value      = <bool, int, float, string> | 'any' | [value0, value1, ...]
```

Use quotes around `>` and `<` on the command line. Replace spaces in string values with underscores.

**Available fields:**

| Name | Type | Description |
| --- | --- | --- |
| `duration` | float | Max rental duration in days |
| `geolocation` | string | Two-letter country code (supports `=`, `!=`, `in`, `notin`) |
| `id` | int | Volume offer unique ID |
| `inet_down` | float | Internet download speed in Mb/s |
| `inet_up` | float | Internet upload speed in Mb/s |
| `reliability` | float | Machine reliability score |
| `storage_cost` | float | Storage cost in $/GB/month |
| `verified` | bool | Is the machine verified |

## Examples

```bash
# Search for network volumes with fast upload
vastai search network-volumes "inet_up>500"

# Search with no default filters
vastai search network-volumes -n "storage_cost<0.10"
```

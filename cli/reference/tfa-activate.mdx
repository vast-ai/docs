Complete the 2FA setup process by verifying your code

## Usage

```bash
vastai tfa activate CODE --secret SECRET [--method-type METHOD_TYPE] [--phone-number PHONE_NUMBER] [--label LABEL]
```

## Arguments

<ParamField path="code" type="string" required>
  6-digit verification code from SMS or Authenticator app
</ParamField>

## Options

<ParamField path="-t" type="string">
  New 2FA Method type to activate (alias: `--method-type`). Allowed values: `sms`, `totp`
</ParamField>

<ParamField path="--secret" type="string" required>
  Secret token from setup process
</ParamField>

<ParamField path="--phone-number" type="string">
  Phone number for SMS method (E.164 format)
</ParamField>

<ParamField path="-l" type="string">
  Label for the new 2FA method (alias: `--label`)
</ParamField>

## Description

Complete the 2FA setup process by verifying your code. Prior to running this command, you must authorize via `vastai tfa auth-new`.

For TOTP:
1. Run `vastai tfa totp-setup`
2. Enter key or scan QR code in your authenticator app
3. Run this command with the 6-digit code and secret

For SMS:
1. Run `vastai tfa send-sms`
2. Run this command with the code received via SMS and your phone number

## Examples

```bash
vastai tfa activate --method-type totp --secret abc123def456 123456
```

```bash
vastai tfa activate --method-type sms --secret abc123def456 --phone-number +12345678901 123456
```

```bash
vastai tfa activate --method-type sms --secret abc123def456 --phone-number +12345678901 --label "Work Phone" 123456
```

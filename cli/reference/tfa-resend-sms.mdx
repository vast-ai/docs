Resend SMS verification code

## Usage

```bash
vastai tfa resend-sms --secret SECRET [--phone-number PHONE_NUMBER]
```

## Options

<ParamField path="-s" type="string" required>
  Secret token from original 2FA request (alias: `--secret`)
</ParamField>

<ParamField path="-p" type="string">
  Phone number in E.164 format (alias: `--phone-number`)
</ParamField>

## Description

Resend an SMS verification code. Useful if you did not receive the original SMS, the code expired, or you deleted the message. You must provide the same secret from the original request.

## Examples

```bash
vastai tfa resend-sms --secret abc123def456
```

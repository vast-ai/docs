Accept one or more pending host price increases

## Usage

```bash
vastai accept price-increase ID [ID ...] [--yes]
```

## Arguments

<ParamField path="ids" type="integer" required>
  One or more instance IDs to accept price increases for
</ParamField>

## Options

<ParamField path="--yes" type="boolean">
  Skip the interactive confirmation prompt. Required when stdin is not a TTY (alias: `-y`)
</ParamField>

## Description

Review pending price increases with `vastai show pending-price-increases` before accepting. The CLI sends one PUT per instance ID (no batch endpoint exists on the backend). The new rate applies only after each contract's current end date — your remaining time on the current term is billed at the original price.

**Exit codes:**
- `0` — every requested row was accepted
- `1` — at least one row failed (non-stale)
- `2` — at least one row was stale (re-run `show pending-price-increases`)

## Examples

```bash
# Accept price increase for a single instance
vastai accept price-increase 123 --yes

# Accept for multiple instances at once
vastai accept price-increase 1 2 3 --yes
```

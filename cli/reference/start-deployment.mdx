Start a stopped deployment

## Usage

```bash
vastai start deployment ID [OPTIONS]
```

## Arguments

<ParamField path="id" type="integer" required>
  ID of the deployment to start
</ParamField>

## Description

Starts (or restarts) the endpoint associated with a deployment. Use this to resume a deployment that was previously stopped with `vastai stop deployment`.

## Examples

```bash
# Start deployment 1234
vastai start deployment 1234

# Start and get raw JSON response
vastai start deployment 1234 --raw
```

## Global Options

The following options are available for all commands:

| Option | Description |
| --- | --- |
| `--url URL` | Server REST API URL |
| `--retry N` | Retry limit |
| `--raw` | Output machine-readable JSON |
| `--explain` | Verbose explanation of API calls |
| `--api-key KEY` | API key (defaults to `~/.config/vastai/vast_api_key`) |

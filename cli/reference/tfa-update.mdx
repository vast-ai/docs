Update a 2FA method's label or primary status.

## Usage

```bash
vastai tfa update METHOD_ID [--label LABEL] [--set-primary]
```

## Arguments

<ParamField path="METHOD_ID" type="integer" required>
  ID of the 2FA method to update. Use `vastai tfa status` to list your methods and their IDs.
</ParamField>

## Options

<ParamField path="--label" type="string">
  New label/name for this method (e.g., "Work Phone"). (alias: `-l`)
</ParamField>

<ParamField path="--set-primary" type="boolean">
  Set this method as the primary/default 2FA method. (alias: `-p`)
</ParamField>

## Description

Update the label or primary status of an existing 2FA method. The label is a friendly name to help you identify the method (e.g., "Work Phone", "Backup Authenticator"). Setting a method as primary makes it the default method used for 2FA challenges.

## Examples

```bash
# Rename a 2FA method
vastai tfa update 123 --label "Work Phone"
```

```bash
# Set a method as primary
vastai tfa update 456 --set-primary
```

```bash
# Update both label and primary status
vastai tfa update 789 --label "Backup Authenticator" --set-primary
```

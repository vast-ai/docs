Request a 2FA SMS verification code.

## Usage

```bash
vastai tfa send-sms [--phone-number PHONE_NUMBER]
```

## Options

<ParamField path="--phone-number" type="string">
  Phone number in E.164 format (e.g., `+1234567890`). If not provided, uses the phone number on your account. (alias: `-p`)
</ParamField>

## Description

Request a 2FA verification code to be sent via SMS. If `--phone-number` is not provided, the code is sent to the phone number already associated with your account.

The command returns a secret token that must be used with `vastai tfa activate` to complete the 2FA setup process.

## Examples

```bash
# Send SMS to the phone number on your account
vastai tfa send-sms
```

```bash
# Send SMS to a specific phone number
vastai tfa send-sms --phone-number +12345678901
```

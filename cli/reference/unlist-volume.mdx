Stop advertising a volume offer.

<Note>
  This is a **host** command. Unlisting an offer is different from a renter permanently deleting an owned volume. See [Volume Offers](/host/volume-offers).
</Note>

## Usage

```bash
vastai unlist volume ID
```

## Arguments

<ParamField path="id" type="integer" required>
  ID of the volume offer you want to unlist
</ParamField>

## Examples

```bash
vastai unlist volume <ID>
```

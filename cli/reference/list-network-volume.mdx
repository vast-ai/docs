[Host] List disk space for rent as a network volume

## Usage

```bash
vastai list network-volume DISK_ID [OPTIONS]
```

## Arguments

<ParamField path="disk_id" type="integer" required>
  ID of the network disk to list
</ParamField>

## Options

<ParamField path="-p" type="float" default="0.15">
  Storage price in $/GB/month (alias: `--price_disk`)
</ParamField>

<ParamField path="-e" type="string">
  Contract offer expiration date (unix timestamp or `MM/DD/YYYY` format, default: 1 month) (alias: `--end_date`)
</ParamField>

<ParamField path="-s" type="integer" default="15">
  Size of disk space allocated to the offer in GB (alias: `--size`)
</ParamField>

## Description

Allocates a section of a network disk for rent as a network volume. This is a host-side command for machine operators.

## Examples

```bash
# List a 100GB network volume at $0.15/GB/month
vastai list network-volume 42 --size 100

# List with custom pricing and expiration
vastai list network-volume 42 --size 200 --price_disk 0.20 --end_date 12/31/2025
```

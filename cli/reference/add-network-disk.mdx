[Host] Add a network disk to a physical cluster

## Usage

```bash
vastai add network-disk MACHINES MOUNT_PATH [OPTIONS]
```

## Arguments

<ParamField path="machines" type="integer" required>
  One or more machine IDs to add the network disk to (must be on the same LAN)
</ParamField>

<ParamField path="mount_point" type="string" required>
  Mount path of the disk to add
</ParamField>

## Options

<ParamField path="-d" type="integer">
  ID of an existing network disk to attach to machines in the cluster (alias: `--disk_id`). Required when adding a second or subsequent disk
</ParamField>

## Description

Adds a network disk to a physical cluster of machines. When adding a network disk for the first time, specify only the machine(s) and mount path. When adding a disk that already exists, also specify its `--disk_id`.

## Examples

```bash
# Add a new network disk to machine 1
vastai add network-disk 1 /mnt/disk1

# Attach an existing network disk (ID 12345) to machine 1
vastai add network-disk 1 /mnt/disk1 -d 12345

# Add a network disk to multiple machines
vastai add network-disk 1 2 3 /mnt/shared
```

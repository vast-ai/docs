Request a 2FA code via Email.

## Usage

```bash
vastai tfa send-email
```

## Description

Request a 2FA verification code to be sent to your account's email address. No arguments or options are needed beyond the global options.

The command returns a secret token that must be used with `vastai tfa activate` to complete the 2FA setup process.

## Examples

```bash
vastai tfa send-email
```

## Global Options

The following options are available for all commands:

| Option | Description |
| --- | --- |
| `--url URL` | Server REST API URL |
| `--retry N` | Retry limit |
| `--raw` | Output machine-readable JSON |
| `--explain` | Verbose explanation of API calls |
| `--api-key KEY` | API key (defaults to `~/.config/vastai/vast_api_key`) |

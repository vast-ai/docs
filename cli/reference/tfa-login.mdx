Complete 2FA login by providing the verification code

## Usage

```bash
vastai tfa login [--code CODE] [--method-type METHOD_TYPE] [--secret SECRET] [--backup-code BACKUP_CODE] [--method-id METHOD_ID]
```

## Options

<ParamField path="-c" type="string">
  2FA code (alias: `--code`)
</ParamField>

<ParamField path="-t" type="string">
  2FA Method type (alias: `--method-type`). Allowed values: `email`, `sms`, `totp`
</ParamField>

<ParamField path="-s" type="string">
  Secret token, required for SMS or Email (alias: `--secret`)
</ParamField>

<ParamField path="-bc" type="string">
  One-time backup code (alias: `--backup-code`)
</ParamField>

<ParamField path="-id" type="string">
  2FA Method ID (alias: `--method-id`)
</ParamField>

## Description

Complete 2FA login by providing the verification code.

For Email: use `--method-type email` with `--secret` from `vastai tfa send-email`.

For TOTP: use `--method-type totp` with the 6-digit code from your authenticator app.

For SMS: use `--method-type sms` with `--secret` from `vastai tfa send-sms`.

For backup codes: use `--backup-code` with a one-time backup code.

## Examples

```bash
vastai tfa login --method-type totp -c 123456
```

```bash
vastai tfa login --method-type sms --code 123456 --secret abc123def456
```

```bash
vastai tfa login -t email -c 123456 -s abc123def456
```

```bash
vastai tfa login --backup-code ABCD-EFGH-IJKL
```

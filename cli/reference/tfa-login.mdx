Complete 2FA login by verifying your identity with a 2FA code or backup code. On success, saves the session key to `~/.config/vastai/vast_tfa_key`.

## Usage

```bash
vastai tfa login [--code CODE] [--method-type METHOD_TYPE] [--secret SECRET] [--backup-code BACKUP_CODE] [--method-id ID] [--lifetime-sec SECONDS]
```

## Options

<ParamField path="--code" type="string">
  2FA code from Authenticator app, SMS, or Email. Exactly one of `--code` or `--backup-code` is required. (alias: `-c`)
</ParamField>

<ParamField path="--backup-code" type="string">
  One-time backup code (alternative to regular 2FA code). Exactly one of `--code` or `--backup-code` is required. (alias: `-bc`)
</ParamField>

<ParamField path="--method-type" type="string">
  2FA method type. Choices: `email`, `sms`, `totp`. Only use when you have exactly one method of this type. (alias: `-t`)
</ParamField>

<ParamField path="--secret" type="string">
  Secret token from the previous login step. Required for SMS or Email 2FA (obtained from `tfa send-sms` or `tfa send-email`). (alias: `-s`)
</ParamField>

<ParamField path="--method-id" type="string">
  2FA method ID if you have more than one of the same type. Get the ID from `vastai tfa status`. (alias: `-id`)
</ParamField>

<ParamField path="--lifetime-sec" type="number">
  Seconds the 2FA session lives (60 or more, at most a day). Default: a day. The session never outlives the API key you log in with.
</ParamField>

## Description

Running `tfa login` again while the session is live renews it with a new code. An authenticator code works once: after a login, wait for your app to show the next code before using it for another 2FA action. A reused code is refused with `tfa_code_used`.

## Examples

```bash
# Login with TOTP (Authenticator app)
vastai tfa login --method-type totp -c 123456

# A 15-minute session
vastai tfa login --method-type totp -c 123456 --lifetime-sec 900

# Login with SMS (get code and secret from send-sms first)
vastai tfa login --method-type sms --code 123456 --secret abc123def456

# Login with Email
vastai tfa login -t email -c 123456 -s abc123def456

# Login with backup code
vastai tfa login --backup-code ABCD-EFGH-IJKL
```

The following options are available for all commands:

| Option | Description |

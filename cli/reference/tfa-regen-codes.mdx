Generate new backup codes

## Usage

```bash
vastai tfa regen-codes [--code CODE] [--method-type METHOD_TYPE] [--secret SECRET] [--backup-code BACKUP_CODE] [--method-id ID]
```

## Options

<ParamField path="-c" type="string">
  2FA code (alias: `--code`)
</ParamField>

<ParamField path="-t" type="string">
  2FA Method type (alias: `--method-type`). Allowed values: `email`, `sms`, `totp`
</ParamField>

<ParamField path="-s" type="string">
  Secret token, required for SMS or Email (alias: `--secret`)
</ParamField>

<ParamField path="-bc" type="string">
  One-time backup code (alias: `--backup-code`)
</ParamField>

<ParamField path="-id" type="string">
  2FA Method ID (alias: `--method-id`)
</ParamField>

## Description

Generate new backup codes. Requires 2FA verification.

**WARNING:** This will invalidate all existing backup codes. Regenerate when you are running low on codes, codes may be compromised, or codes are lost. Save the new codes immediately — they will not be shown again.

## Examples

```bash
vastai tfa regen-codes --method-type totp --code 123456
```

```bash
vastai tfa regen-codes -c 123456 -t sms --secret abc123def456
```

```bash
vastai tfa regen-codes --backup-code ABCD-EFGH-IJKL
```

Authorize your account to add a new 2FA method

## Usage

```bash
vastai tfa auth-new [--method-type METHOD_TYPE | --method-id ID | --backup-code BACKUP_CODE] [--secret SECRET --code CODE]
```

## Options

<ParamField path="-c" type="string">
  2FA code from Authenticator app, SMS, or Email (alias: `--code`)
</ParamField>

<ParamField path="-s" type="string">
  Secret token from previous auth step (alias: `--secret`)
</ParamField>

<ParamField path="-t" type="string">
  2FA Method type (alias: `--method-type`). Allowed values: `email`, `sms`, `totp`
</ParamField>

<ParamField path="-bc" type="string">
  One-time backup code (alias: `--backup-code`)
</ParamField>

<ParamField path="-id" type="string">
  2FA Method ID from `tfa status` (alias: `--method-id`)
</ParamField>

## Description

Authorize your account to add a new 2FA method. This is a required step before adding new methods.

Step 1: Run with your chosen verification method (existing method, email, or backup code).

Step 2: Enter the 2FA code to confirm. If you exit early, re-run with `--secret` and `--code`.

## Examples

```bash
vastai tfa auth-new
```

```bash
vastai tfa auth-new --method-type totp
```

```bash
vastai tfa auth-new -t sms
```

```bash
vastai tfa auth-new --method-id 456
```

```bash
vastai tfa auth-new --backup-code ABCD-EFGH-IJKL
```

```bash
vastai tfa auth-new --secret abc123def456 --code 123456
```

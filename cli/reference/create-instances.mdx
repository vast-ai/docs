Create multiple instances from a list of offer IDs in parallel

## Usage

```bash
vastai create instances ID0 ID1 ID2... [OPTIONS] [--args ...]
```

## Arguments

<ParamField path="ids" type="integer" required>
  One or more offer IDs to launch (returned from `search offers`)
</ParamField>

## Options

<ParamField path="--template_hash" type="string">
  Create instances from template info
</ParamField>

<ParamField path="--image" type="string">
  Docker container image to launch
</ParamField>

<ParamField path="--disk" type="float" default="10">
  Size of local disk partition in GB
</ParamField>

<ParamField path="--login" type="string">
  Docker login arguments for private repo authentication (surround with quotes)
</ParamField>

<ParamField path="--label" type="string">
  Label to set on the instance
</ParamField>

<ParamField path="--onstart" type="string">
  Filename to use as onstart script
</ParamField>

<ParamField path="--onstart-cmd" type="string">
  Contents of onstart script as single argument
</ParamField>

<ParamField path="--entrypoint" type="string">
  Override entrypoint for args launch instance
</ParamField>

<ParamField path="--ssh" type="boolean">
  Launch as an SSH instance type
</ParamField>

<ParamField path="--jupyter" type="boolean">
  Launch as a Jupyter instance instead of an SSH instance
</ParamField>

<ParamField path="--direct" type="boolean">
  Use (faster) direct connections for Jupyter and SSH
</ParamField>

<ParamField path="--jupyter-dir" type="string">
  Directory in instance to use to launch Jupyter (defaults to image's working directory)
</ParamField>

<ParamField path="--jupyter-lab" type="boolean">
  Launch instance with Jupyter Lab
</ParamField>

<ParamField path="--env" type="string">
  Environment variables and port mapping options (surround with quotes)
</ParamField>

<ParamField path="--args" type="string">
  List of arguments passed to container ENTRYPOINT (must be last argument)
</ParamField>

<ParamField path="--force" type="boolean">
  Skip sanity checks when creating from an existing instance
</ParamField>

<ParamField path="--cancel-unavail" type="boolean">
  Return error if scheduling fails (rather than creating a stopped instance)
</ParamField>

<ParamField path="--bid_price" type="float">
  Create INTERRUPTIBLE (spot) instances with per machine bid price in $/hour
</ParamField>

<ParamField path="--create-volume" type="integer">
  Create a new local volume using an ID from `search volumes` and link it to each new instance
</ParamField>

<ParamField path="--link-volume" type="integer">
  ID of an existing rented volume to link to the instance during creation
</ParamField>

<ParamField path="--volume-size" type="integer">
  Size of the volume to create in GB. Only usable with `--create-volume` (default 15 GB)
</ParamField>

<ParamField path="--mount-path" type="string">
  Path to the volume from within the new instance container (e.g. `/root/volume`)
</ParamField>

<ParamField path="--volume-label" type="string">
  A name to give the new volume (only usable with `--create-volume`)
</ParamField>

## Description

Bulk-creates instances from multiple offer IDs in parallel (up to 8 threads, batches of 64). Takes the same options as `create instance` but accepts multiple IDs.

## Examples

```bash
# Create 3 instances from different offers with the same template
vastai create instances 384826 384827 384828 --template_hash 661d064bbda1f2a133816b6d55da07c3 --disk 64

# Create spot instances on multiple offers
vastai create instances 100 200 300 --image pytorch/pytorch --disk 40 --ssh --direct --bid_price 0.10
```

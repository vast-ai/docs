# Host docs review presentation

The presentation, setup instructions, and Owner questions are included in the PR checkout.

After starting the docs preview and review server, open:

http://127.0.0.1:4000/__review__/presentation/

You can also click **Review presentation** in the review panel or review dashboard.

## Follow the video

- **Run the unmerged PR locally** opens the copyable Git and server commands.
- **Evidence on GitHub** opens the retained hardware test records used in the examples.
- **Owner questions** opens the questions, affected passages, and requested owner decisions.
- The reviewer itself is at http://127.0.0.1:4000/host/hosting-overview.
- Port 3000 is the plain docs preview; port 4000 adds the review tools.

The video includes captions and a three-second opening pause. Downloads are available below the player. Hardware test records retain the scope of the actual runs. Feedback entered in the review overlay saves in your checkout and can be exported for Jira.

The Owner questions page retains its dated source snapshot and links to the corresponding passage coverage. Use the linked Jira issues when recording owner answers.

## Files

- `index.html`: presentation and video player
- `reviewer-setup.html`: setup commands and troubleshooting
- `owner-questions.html`: owner decisions and linked passages
- `host-docs-review.html`: retained passage coverage
- `speaker-script.md`: full narration
- `deliverables/host-docs-review-walkthrough/`: MP4, audio and captions

The editable production pipeline and narration authorization records are retained in the working presentation project; they are not needed to watch or review this package.

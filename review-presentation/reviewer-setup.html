Run the commands from a parent directory where you keep review projects. If docs-pr185 already exists, use the update steps below or choose a different new folder name in the first two commands.

Step 2 · Keep both terminals running

Start the docs and review overlay

Run both commands from the same docs-pr185 folder, in two terminals.

TERMINAL 1 · DOCS ON PORT 3000
npm run dev:review -- --port 3000

Wait for the docs server to be ready.

TERMINAL 2 · REVIEW OVERLAY ON PORT 4000
node review-server.mjs --host 127.0.0.1 --port 4000 --target http://127.0.0.1:3000
PRESENTATION · VIDEO, SETUP COMMANDS, OWNER QUESTIONS http://127.0.0.1:4000/__review__/presentation/

Open it with Review presentation in the review panel.

HOST DOCS · OPEN THE PAGE, THEN CLICK REVIEW http://127.0.0.1:4000/host/hosting-overview

Port 3000 shows the plain docs. Port 4000 adds the review tools.

Terminal 1 can stay in the checkout after npm ci. Open Terminal 2 in that same folder, or use cd with its full path. The overlay command above is one command; its visual line wrap is only for readability.

The docs command uses the repository's loopback wrapper. The overlay also listens on 127.0.0.1. Keep both processes running while you review; stop each with Ctrl + C when finished.

Open the presentation first to watch the walkthrough, copy these setup commands, and open Owner questions. Review notes save in your browser; use the export controls to include them in Jira.

When the pull request changes

Update your review checkout

Stop both servers. In the same docs-pr185 folder, inspect your working tree first:

git status --short

For an unchanged review checkout, the status output should be empty. If you edited files or made commits, preserve that work on a branch before switching versions. Then fetch the new PR head and install its locked dependencies:

git fetch origin pull/185/head
git switch --detach FETCH_HEAD
npm ci

Start the two servers again with the commands above. These instructions do not reset or clean your files, and they do not merge the pull request.

If the page does not open

Check the local setup

The Review button is missing.
Open port 4000, not port 3000. Confirm Terminal 2 is still running.
The overlay cannot reach the docs.
Wait until Terminal 1 is ready, then open the plain docs on port 3000. Confirm the overlay's --target matches that address.
A command is not found or dependencies fail.
Check git --version, node --version and npm --version. Use Node.js 24 LTS, run npm ci inside the checkout, and read the terminal's first error. The first installation needs internet access.
A port is already in use.
Use an available port. If the docs port changes, update the overlay's --target. If the overlay port changes, open that new port in your browser.

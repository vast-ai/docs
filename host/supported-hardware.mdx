Use this page before buying hardware, installing the host software, or listing a machine.

<Note>
Meeting minimum requirements makes a machine eligible. It does not guarantee verification, search placement, rentals, or earnings.
</Note>

## Quick Check

A typical Vast host needs:

- Native Ubuntu Server; check the architecture guidance below before selecting x86_64/AMD64 or ARM64 hardware.
- Same-type GPUs.
- NVIDIA Maxwell or newer GPUs for the current verification path. Confirm AMD listing compatibility separately before choosing an AMD host.
- More than 7 GiB VRAM per GPU for CLI self-test preflight; also review the published verification requirements.
- An AVX-capable x86_64 CPU. For ARM64, clarify the published AVX requirement with Vast before choosing the hardware.
- At least two physical CPU cores per listed GPU for the current verification requirements. Hyperthreads do not count as physical cores.
- Enough system RAM for the GPU tier.
- Fast SSD/NVMe storage with at least a 200 GB dedicated Docker partition, plus capacity for the workloads you plan to offer.
- Public inbound networking with direct TCP and UDP port forwarding.

## GPU Support

| Vendor | Guidance |
| --- | --- |
| NVIDIA | Maxwell or newer for the current verification path. Check current demand by GPU model; newer hardware does not guarantee rentals. |
| AMD | MI25 or newer Radeon Instinct, Radeon VII, Radeon Pro VII, Radeon RX 7900 GRE/XT/XTX, and Radeon Pro W7900/W7800. Other 6000-series or newer Radeon RX/Pro W GPUs may work, but may not appear in standard ROCm filters. |

Avoid mixed GPU models unless Vast explicitly documents support for that setup.

If a new GPU model is not listed or searchable yet, ask Vast to add it through support or the [host community channels](/host/community).

## Hardware Planning

| Area | Baseline |
| --- | --- |
| OS | Ubuntu 24.04 LTS preferred; Ubuntu 22.04 also works. |
| Machine use | Dedicated host machine while rented. |
| CPU | At least two physical cores per GPU for current verification requirements. Use an AVX-capable x86_64 CPU; clarify the published ARM64/AVX requirement before choosing ARM64. |
| System RAM | At least 95% of total GPU VRAM for the current verification requirements; plan further capacity for the intended workload. |
| Storage | Fast SSD/NVMe with at least a 200 GB dedicated Docker partition, sized further for the intended workloads. |
| PCIe | Enough lanes/bandwidth for the GPUs; avoid unstable risers, power, and BIOS layouts. |
| Network | Reliable public inbound connectivity for the configured port range. |

For current verification thresholds, see [Verification Stages](/host/verification-stages#additional-requirements-for-verification).

## Balance Matters

A strong GPU can still be a poor host if the rest of the machine is weak. Match CPU, RAM, PCIe, storage, cooling, power, and network capacity to the GPU tier.

Avoid reducing GPU count, RAM, disk, or other capacity after the machine is created; reductions can trigger deverification.

## Storage And Network

Docker storage should be fast, predictable, and mounted before Docker starts. Vast uses XFS project quotas for per-container storage limits. See [Storage Setup](/host/storage-setup).

Hosts need public inbound connectivity for supported direct access. CGNAT, double NAT without a public forwarding path, blocked ports, IPv6-only service, LAN-only forwarding, packet loss or unstable upload can break connectivity checks or renter access even when a machine is listed. See [Network & Ports](/host/network-ports).

## Unsupported Or Discouraged Setups

| Setup | Why |
| --- | --- |
| Windows or WSL as the host OS | Vast hosting is built for native Linux hosts. |
| ARM or GB10-class systems | The published setup lists ARM64 but also specifies AVX. Confirm architecture-specific requirements and GB10 support with Vast before choosing this path. |
| Mixed GPU models | Current verification requirements call for identical GPU models in a machine. |
| Low-VRAM or very old GPUs | The CLI preflight requires more than 7 GiB VRAM per GPU. Check [GPU Market Metrics](/host/market-metrics) for the model before buying. |
| Gaming/workstation use during rentals | Avoid workloads that compete with renter work; see the [Hosting Agreement’s noninterference rule](https://cloud.vast.ai/host/agreement). |
| No public inbound networking | Connectivity checks and renter access can fail. |

## Before You Buy

Confirm GPU demand with [GPU Market Metrics](/host/market-metrics), then verify CPU, RAM, PCIe, storage, and networking before spending money. After hardware is ready, continue with [Hosting Quickstart](/host/quickstart).

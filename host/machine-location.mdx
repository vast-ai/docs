---
title: "Fix Your Machine's Listed Location"
description: "Set the location renters see for your machine when it connects through a VPN or proxy and is listed in the wrong place."
---

Vast lists each machine at the location of the IP address it connects from. If your machine
reaches the internet through a VPN, a proxy or a tunnel, that address belongs to the exit
point, not to your machine, and renters see the wrong country or region.

You can set the location yourself. The value you set is shown to renters, used by location
filters in search, and kept until you clear it: the automatic lookup no longer changes it.

<Note>
Setting the location is currently done from the [CLI](/cli/reference/set-machine-override)
or the [API](/api-reference/machines/set-machine-override). Set the place where the machine
physically is: an incorrect location may be corrected by Vast support, and a location set
by support can't be changed from your account.
</Note>

---

## Set the location

The location is written as `"Region, CC"` for machines in the United States, China, Canada
and Russia, and as `"Country, CC"` everywhere else, where `CC` is the two-letter country code:

| Machine in | Value |
| --- | --- |
| Guangdong, China | `"Guangdong, CN"` |
| California, United States | `"California, US"` |
| Germany | `"Germany, DE"` |

Set it on one or more machines:

```bash
vastai set machine-override geolocation "Guangdong, CN" --ids 12345,12346
```

Leave out `--ids` to set it on all of your machines:

```bash
vastai set machine-override geolocation "Guangdong, CN"
```

The new location appears on your machines and their offers right away.

## Go back to automatic detection

Clearing the value restores the location detected from the machine's IP address:

```bash
vastai clear machine-override geolocation --ids 12345
```

## If the location can't be changed

If the command reports that a machine has a value set by Vast support, the location was
corrected by support and can't be changed from your account. Contact support if it is wrong.
